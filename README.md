# settlein-student-housing

**SettleIn** is a comprehensive student-focused accommodation marketplace designed to streamline the process of finding suitable housing near universities in Kenya. It connects students with verified property managers through a secure, transparent, and user-friendly platform.

## ✨ Features

- **Student-Centric Design**: Modern, intuitive interface tailored for university students.
- **Verified Listings**: Property managers must complete a verification process before listing properties.
- **Landlord Portal**: Dedicated interface for property managers to manage listings, view messages, and track applications.
- **Secure Messaging**: Built-in chat system for direct communication between students and landlords.
- **Advanced Filtering**: Search and filter properties by price, location, number of rooms, and amenities.
- **Responsive UI**: Seamless experience across desktop, tablet, and mobile devices.

## 🚀 Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animation**: Framer Motion

## 📂 Project Structure

The project follows a clear separation of concerns:

- `app/src/components/`: Reusable UI components.
- `app/src/views/`: Main application views (Home, Listings, Profile, etc.).
- `app/src/api/`: Mock API functions for data fetching.
- `app/src/assets/`: Static assets and images.
- `app/src/lib/`: Utility functions and helpers.

## 🏃 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm (or yarn/pnpm)

### Installation

1.  Clone the repository:
    ```bash
    git clone <repository-url>
    cd app
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

### Running the Application

Start the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser.
