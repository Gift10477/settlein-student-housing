SettleIn Student Accommodation API (1.0.0)

Download OpenAPI specification:

SettleIn Engineering Team (Gift Githaka, Ian Kungu, Yahya Abdi, Tiffany Olale): support@settlein.strathmore.edu License: MIT

Official OpenAPI 3.0 contract for SettleIn (Team 1) — Student Housing & Accommodation Marketplace. This contract specifies the interface exposed to our downstream ring partner, StudySync (Team 2), for student residential locations, accommodation study amenities, lease timelines, verified student identities, and co-living group inquiries.

Students & Location

Retrieve student residential estate and campus proximity

Returns the student's residential estate name, calculated distance/commute to campus, and nearest campus branch. Used by StudySync to identify central meetup locations and recommend convenient study group venues without requiring exact GPS coordinates. Exact building and room numbers remain private.

path Parameters
id
required
integer >= 1
Example: 1042

Unique integer ID of the student user.
